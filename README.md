# AiVideo

在本目录执行：

    uv sync
    uv run python aivideo_gui.py

粘贴 B 站 BV 号、作品链接或抖音单条视频分享链接，点击“查询视频”可同时查看封面与可用画质；选择画质、保存目录和输出格式后开始下载。可输出视频、WAV 音频、人声转写 TXT（UTF-8，带时间戳），至少选择一种。TXT 只识别人声，不识别画面文字。

同一保存目录中已有该作品的 MP4 时，会直接复用它生成 WAV/TXT；只选 WAV 或 TXT 也不会重新下载或删除已有 MP4。语音识别在独立进程中运行，识别失败会在界面显示错误。

窗口关闭时会将大小、位置、下载目录和输出格式选择保存到项目内的 `.user-settings.ini`，下次启动自动恢复。首次启动的窗口大小在 `aivideo_gui.py` 的 `MainWindow.__init__` 中设置。

已有本地视频时，勾选 WAV 或人声 TXT，再点击“从本地视频生成 WAV / TXT”选择视频文件。输出保存在视频所在目录，原视频会保留，不会再次下载。

需要 Python 3.11+。首次运行先执行 `uv sync` 安装依赖。首次转写时 `faster-whisper` 会下载 small 模型，使用本机 CPU 识别，可能需要较长时间。视频处理使用项目内 `ffmpeg/bin/ffmpeg.exe`，配置见 `.env.example`。B 站部分画质可能需要在本地 `.env` 配置登录 Cookie。下载结果取决于平台当前提供的流及访问权限。

B 站下载请求会带视频页 Referer 和 `Range` 请求头；若主媒体地址不可用，会依次尝试同一画质的备用地址。所有地址均不可用时会报错，不会自动降低画质。

抖音查询会启动独立的 Chrome 浏览器环境，打开作品页面并读取页面返回的作品详情，以获取封面和画质；下载时会重新取得有效的视频地址。首次启动浏览器可能稍慢。浏览器数据保存在项目内的 `.browser-profile`，不读取日常 Chrome/Edge 的 Cookie 数据库。部分作品仍可能受到登录要求或平台访问限制。
