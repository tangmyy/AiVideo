# 音频与人声转写设计

用户确认采用本地语音识别：从下载的视频取得音频，导出 WAV，并将人声转写为 UTF-8 TXT。当前统一界面 `aivideo_gui.py` 是正式入口；旧的 `bilibili_gui.py` 仅是兼容启动包装，无其他代码依赖，已移除并同步更新 README。

在现有画质查询和保存目录下增加三个输出选项：保存视频（默认）、导出 WAV、识别人声并导出 TXT。至少选择一项；一次下载可生成多个输出。WAV 用项目已有 FFmpeg 转为 PCM 16 位；TXT 由本地 `faster-whisper` 的 small 模型、CPU int8 模式生成，每段包含时间戳。首次转写需下载模型。若只选择 TXT，WAV 为临时文件；若未选择视频，成功生成其他文件后删除下载的视频。后处理失败时保留已下载的视频，便于重试。

下载与导出均在后台线程。状态依次显示下载、提取音频、识别人声、完成；TXT 文件写入临时路径后原子替换，避免留下半成品。语音识别只处理人声，不识别画面字幕；准确度受噪音、音乐、方言和模型能力影响。批量下载、OCR、云端转写和模型选择暂不加入。
